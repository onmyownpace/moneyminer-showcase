# Demo storyboard (45–90 seconds)

Short Upwork / portfolio walkthrough. Narrate calmly; show Mission Control on localhost with **sample or redacted** data only. Never show tokens, bank details, private leads, or imply earnings above **$0**.

## Shot list

| Time | Visual | Narration |
|---|---|---|
| 0:00–0:08 | Banner / README hero, then Mission Control window | “MoneyMiner is a local Mission Control for finding funded software work — not a SaaS, and not a bot that spends on its own.” |
| 0:08–0:22 | Agent Army panel: diagram + logical roles | “About seventeen logical roles share one local process — hunters, verifiers, prep, proposals, payment tracking. They’re roles and workers, not seventeen separate AIs.” |
| 0:22–0:38 | Opportunities / Discovery (empty or sanitized) | “Discovery pulls public signals, then validation checks funding, competition, and payout terms. Missing evidence stays unknown.” |
| 0:38–0:55 | Execution gate (*awaiting approval*) | “When something looks promising, MoneyMiner prepares local fixes and tests — then stops. Claims and applications wait for a human GO.” |
| 0:55–1:10 | Earnings panel showing **$0.00** | “The earnings view only counts real ledger payments. Today that’s zero — estimates never get dressed up as money received.” |
| 1:10–1:25 | Optional: architecture SVG or roles-vs-models | “Pipeline is discover → validate → prioritize → human approval → prep → track. Cloud agents that *build* MoneyMiner are separate from the local army.” |
| 1:25–1:30 | End card: repo URL + “showcase only” | “Public showcase for portfolio review. Product source stays private.” |

## Do / don’t

- **Do** say human approval is required for external actions  
- **Do** show the $0 earnings panel if you show money at all  
- **Don’t** claim autonomous payouts or revenue  
- **Don’t** paste private repo links as if they were public  
- **Don’t** invent UI mockups — use real Mission Control or clearly labeled diagrams  

## Recording tips

- 1440×900 or 1280×720; dark UI reads well compressed  
- Mute notifications; hide browser bookmarks bar  
- Prefer a quiet 60s cut over a long tour
